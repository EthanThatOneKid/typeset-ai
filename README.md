# Typeset AI

Landing page for **Typeset AI** — a tool that turns messy webpages, dashboards, and research into beautifully typeset, print-ready PDFs.

## About

This repo hosts a single-file prototype of the Typeset AI marketing site (`index.html`), including:

- Interactive demo of the URL → document workflow (4 document styles)
- Features, how-it-works, pricing, and FAQ sections
- Fully responsive, zero dependencies — plain HTML/CSS/JS

> The demo shows the interface and interactions only; live URL fetching and PDF export require a backend.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

## Hosting

The site is published with GitHub Pages from the `main` branch.
