05 / Questions, answered

Print is a medium.
Treat it like one.

A few things worth knowing before your first conversion.

How is Typeset different from Print to PDF?

Browser printing captures the current layout. Typeset is designed to interpret a page's content hierarchy and reconstruct it for paper, with document-specific typography and page-break behavior.

Can it handle dashboards and interactive web apps?

That's the goal: flatten interactive elements into useful static representations while preserving important data. Results depend on page access, page complexity, and the implementation of the conversion engine.

Can I tell it what to include or remove?

Yes, the intended workflow includes natural-language instructions such as preserving tables, removing navigation, emphasizing key metrics, or applying an academic layout.

Does this demo generate a real PDF?

Not yet. This standalone prototype demonstrates the interface and interactions. Live URL capture, AI-based reconstruction, secure rendering, and PDF export need a backend service.

What about private pages behind a login?

Authenticated pages require a secure capture mechanism and explicit user-controlled access. Never paste sensitive URLs or confidential data into an untrusted conversion service.
